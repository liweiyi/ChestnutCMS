UPNG quantization core (MIT)
---------------------------
Source package: upng-js 2.1.0, Copyright (c) 2017 Photopea.
Exact source commit: 5e5af183a3dda1e320b90a1830b3f64bc92010d4
https://github.com/photopea/UPNG.js/blob/5e5af183a3dda1e320b90a1830b3f64bc92010d4/UPNG.js
https://registry.npmjs.org/upng-js/-/upng-js-2.1.0.tgz
npm tarball SHA-1: 7176e73973db361ca95d0fa14f958385db6b9dd2
License: UPNG-MIT.txt
Only the palette quantizer and required helpers are vendored as an ESM module
in src/utils/imageOptimizer/vendor/upng-quantize.js. Local changes fix the
power-iteration seed and degenerate/non-finite splits, and expose an ESM entry.
The exact extraction and modifications are recorded in UPNG-SOURCE.md beside
the vendored module. The upstream PNG encoder/decoder and pako are not included.
The adapter uses fixed color-count presets and makes no claim of a perceptual
quality score or target-quality search.

Scope
-----
These records cover newly integrated image packages, licenses included in
those packages, and major codec inputs identified by published build metadata.
The codecs are consumed as published WASM. This work has not independently
reproduced those binaries or proved a complete transitive build closure, and
is not a whole-project license audit. Retain applicable notices when
redistributing. Future package/codec upgrades must recheck build inputs and
license files.
